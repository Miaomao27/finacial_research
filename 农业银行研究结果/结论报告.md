# 农业银行(601288)股价与天干地支五行关系：统计检验结论报告

**日期**: 2026年5月14日  
**数据范围**: 2010-07-15 ~ 2026-05-13 (3,833个交易日, 16年)  
**方法**: 日/周/月三层频率 × Kruskal-Wallis + 样本外验证 + 回归混杂剥离

---

## 一句话结论

**天干地支五行对农业银行股价没有统计上显著的预测能力。** 9个假设检验无一显著，训练集发现的"规律"在测试集上方向反转，确认是过拟合。

---

## 关键证据链

### 证据1：日频 — 完全无差异

| 分组        | 日均收益率   | 标准差    | 上涨占比  | K-W p值      |
| --------- | ------- | ------ | ----- | ----------- |
| 金         | +0.069% | 1.249% | 43.5% |             |
| 木         | +0.040% | 1.325% | 42.7% |             |
| 水         | +0.054% | 1.271% | 44.2% |             |
| 火         | +0.046% | 1.267% | 40.1% |             |
| 土         | +0.019% | 1.165% | 44.4% |             |
| **K-W检验** |         |        |       | **p=0.917** |

5组收益率几乎完全重合，箱线图各分位数基本一致。**p=0.917是所有统计检验中可获得的最高p值之一**——在0到1的区间里这是最强"没关系"信号。

### 证据2：周频 — 滚动窗口围绕零轴波动

3年滚动窗口的"火-金"收益率差异在-36bps，虽有一定幅度，但时序图显示该差异围绕零轴随机波动，不存在长期稳定的方向性偏移。Kruskal-Wallis检验p=0.212（天干）、p=0.307（地支）。

### 证据3：月频 — 训练集发现，测试集反转（经典过拟合）

| 检验       | H统计量 | p值    | 显著? |
| -------- | ---- | ----- | --- |
| 月天干(训练集) | 5.31 | 0.257 | ❌   |
| 月地支(训练集) | 4.79 | 0.310 | ❌   |
| 月天干(测试集) | 6.90 | 0.141 | ❌   |
| 月地支(测试集) | 5.15 | 0.272 | ❌   |

- 训练集最强规律：土(月均+1.13%) > 火(月均-1.47%)
- **测试集方向完全反转**：土(-1.17%) < 火(+0.92%)
- 训练集本身也不显著(p=0.257)，说明在训练集上"找规律"只是在噪声中刻画

### 证据4：回归 — 五行只是阳历的代理变量

| 模型     | R²    | F检验p   | 五行变量显著? |
| ------ | ----- | ------ | ------- |
| 仅月天干五行 | 0.031 | 0.206  | 无       |
| +阳历月份  | 0.095 | 0.038  | ❌ 不显著   |
| +年份    | 0.210 | <0.001 | ❌ 不显著   |

加入阳历月份和年份后，五行变量的系数全部不显著。说明五行与月份存在共线性——这是必然的，因为天干地支本身就是历法系统，与阳历月份高度相关。

### 证据5：稳健性检验

对收益率做1%/99%缩尾处理后，日频K-W检验p=0.917（与原始结果完全一致），结论不变。

---

## 为什么"看起来有规律"？

天干地支是历法的一部分，不同五行对应的月份本身就有季节性。例如：

- **金（庚辛）** 主要出现在秋季（阳历8-9月）——这个季节A股常有利好政策
- **火（丙丁）** 主要出现在夏季（阳历5-6月）——历史上常有利空

这些是阳历效应（日历效应），不是五行本身的预测力。加入月份控制变量后五行信号消失，验证了这一点。

---

## 研究有效性

- ✅ **数据**: 3,833条真实交易数据，非模拟
- ✅ **方法**: 严格的样本外检验（70/30时间分割）
- ✅ **稳健性**: 缩尾处理不改变结论
- ✅ **混杂控制**: 剥离阳历月份 = 日历效应后五行失效
- ✅ **多重检验**: Bonferroni校正后仍然无显著结果

---

## 最终判定

> **否定假设**：天干地支五行不是农业银行股价的可靠预测因子。  
> 这一结论在日、周、月三个时间尺度上一致，经过了样本外验证和混杂因素剥离的检验。  
> *因为统计学上的"没有证据"不是"证据不存在"，但16年的数据和9个检验的结果足够支撑这个结论。*
