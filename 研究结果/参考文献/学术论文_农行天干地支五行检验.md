# 五行炒股指南？——农业银行股价与天干地支关系的统计学检验

> **摘要**：中国传统文化中的天干地支五行学说是否能够预测股市？本研究以农业银行（601288.SH）16年间的3,833个交易日为样本，从日频、周频、月频三个时间尺度，分别检验天干、地支对应五行的收益率差异。我们使用了Kruskal-Wallis非参数检验、样本外验证、多元线性回归混杂剥离和缩尾稳健性检验共计9项测试。**结论斩钉截铁：一个显著的都没有。** 训练集中出现的"土强火弱"规律在测试集上完全反转——这是典型的过拟合。本文的价值不在于发现"有用规律"，而在于证明一个广为流传的民间信仰经不起数据检验，并揭示了"假阳性"的深层来源：日历效应混淆。

---

## 1 引言：当"五行"遇上"A股"

在中文投资社区里，流传着一种迷人的想法：既然天干地支是中国人的时间密码，五行生克是宇宙的运行法则，那么股票走势也理应遵从这套逻辑——"金日宜买，水日宜卖"、"木火日看涨，土金日看空"之类的口诀时有耳闻。甚至连正规金融机构都出现过将天干地支引入研报的争议事件（某券商2021年的"天干地支在投资时钟中的应用"便是一个著名先例）。

这种想法之所以迷人，是因为它提供了一种**看似有文化根基的叙事**。人类天生厌恶随机性，我们总想为市场的布朗运动找到某种"规律"——星座、占星、塔罗牌，亦或是天干地支。这些框架的共同特点在于：它们足够模糊，以至于事后解释总能自圆其说。

但科学的精神不是寻找安慰，而是**证伪**。

本文以中国四大行之一——农业银行（601288.SH）为研究对象，用严格的统计学方法检验一个问题：**天干地支五行真的能影响股票收益率吗？**

选择农业银行的理由有三：（1）流动性充足，日成交额稳定；（2）基本面相对稳健，排除小市值妖股的非理性噪声；（3）这是国有大行，是国家经济的"压舱石"——如果连农业银行的股价都与五行"契合"的话，那或许真值得关注。如果不契合，那这个故事也该到此为止了。

## 2 数据描述

| 指标   | 数值                      |
| ---- | ----------------------- |
| 股票代码 | 601288.SH（农业银行）         |
| 样本区间 | 2010-07-15 至 2026-05-13 |
| 总交易日 | **3,833天**（约16年）        |
| 数据来源 | Tushare Pro             |
| 核心变量 | 每日复权收益率（pct_chg）        |

每个交易日被赋予天干和地支标签（基于干支纪日法），并进一步映射为五行（金、木、水、火、土）。例如，甲子日 → 天干=甲（木）、地支=子（水）。

## 3 研究方法：三层频率 × 多重验证

我们采用了三层频率分析，涵盖从日内到月度的全尺度观测：

**第一层：日频分析**。将3,833个交易日按天干五行分为5组，计算各组收益率分布，采用Kruskal-Wallis非参数检验判断组间是否存在显著差异。同时以地支五行分组做平行检验。辅以1%/99%缩尾（winsorize）处理做稳健性检查。

**第二层：周频分析**。以周为单位取平均收益率，计算3年滚动窗口的五行差异时序，观察规律是否随时间稳定。同样以天干和地支分别检验。

**第三层：月频 + 样本外验证**。这是最关键的一层——将数据按时间顺序70/30分割为训练集（2010-2021）和测试集（2022-2026）。在训练集中"挖掘"最强模式，然后在测试集中验证其是否真实存在。如果训练集发现的规律不能在新数据上复现，那就只是过拟合噪声。

此外，我们还构建了三个OLS回归模型，逐步加入阳历月份和年份虚拟变量，以剥离日历效应的混杂影响。

## 4 实验结果

我们赫然呈上一个干干净净的零结果。

### 4.1 日频：完全无差异

| 五行  | 日均收益率   | 标准差    | 上涨占比  |
| --- | ------- | ------ | ----- |
| 金   | +0.069% | 1.249% | 43.5% |
| 木   | +0.040% | 1.325% | 42.7% |
| 水   | +0.054% | 1.271% | 44.2% |
| 火   | +0.046% | 1.267% | 40.1% |
| 土   | +0.019% | 1.165% | 44.4% |

**Kruskal-Wallis H=0.95, p=0.917。**

p=0.917意味着什么？在0到1的尺度上，这就是统计学能给"没关系"打出的最高分数之一。五组收益率的箱线图几乎完全重合（见图1），没有任何一组表现出系统性偏离。

地支五行的结果同样：H=6.82, p=0.146——同样不显著。

> **图1**：`fig1_daily_boxplot.png` — 日频五组收益率箱线图，中位数、四分位数、极端值几乎完全重合。

### 4.2 周频：滚动窗口无稳定方向

3年滚动窗口的"火-金"差异虽然时有起伏（幅度约±36bps），但时序图显示该差异围绕零轴随机波动，不存在任何长期稳定的方向性偏移（见图2）。

- 周天干：H=5.83, **p=0.212**
- 周地支：H=4.81, **p=0.307**

> **图2**：`fig2_weekly_rolling.png` — 3年滚动窗口收益率差异，围绕零轴随机波动，无稳定趋势。

### 4.3 月频 + 样本外：经典的过拟合教科书

这是整个研究中最有教育意义的部分。

在训练集（2010-2021）上，的确出现了一个"看似漂亮"的模式：土（月均+1.13%）远强于火（月均-1.47%），差值超过2.6个百分点。**但是——该检验本身也不显著（p=0.257）。** 这意味着即使在做数据挖掘的训练集上，这个"规律"也达不到统计学显著的阈值。

果不其然，在测试集（2022-2026）上，规律**完全反转了**：土变成了-1.17%，火变成了+0.92%。训练集上最强的信号，在测试集上成了最弱的。这就是数据挖掘的宿命——在噪声中刻画出的图案，换一段数据就碎了。

| 检验      | H统计量 | p值    | 显著? |
| ------- | ---- | ----- | --- |
| 月天干(训练) | 5.31 | 0.257 | ❌   |
| 月地支(训练) | 4.79 | 0.310 | ❌   |
| 月天干(测试) | 6.90 | 0.141 | ❌   |
| 月地支(测试) | 5.15 | 0.272 | ❌   |

> **图3**：`fig3_monthly_train_test.png` — 训练集与测试集五行收益率对比，方向完全反转。

### 4.4 汇总全景

所有9个Kruskal-Wallis检验的p值汇总（见图4）：

- 日频天干：p=0.917（最高）
- 日频地支：p=0.146
- 周频天干：p=0.212
- 周频地支：p=0.307
- 月天干训练：p=0.257
- 月地支训练：p=0.310
- 月天干测试：p=0.141
- 月地支测试：p=0.272
- 稳健性（缩尾）：p=0.917

**无一低于0.05。** 即便不做Bonferroni校正，9个检验中一个显著结果都没有——这比随机期望还要差（按α=0.05，随机期望应该有0.45个显著结果）。

> **图4**：`fig4_summary_all.png` — 9个检验的p值全景图，均在阈值线之上。

### 4.5 回归分析：五行只是阳历的外衣

为了解释"为什么人们觉得五行有用"，我们做了三步回归：

| 模型    | R²        | F检验p       | 五行变量显著? |
| ----- | --------- | ---------- | ------- |
| 仅天干五行 | 0.031     | 0.206      | 无       |
| +阳历月份 | 0.095     | **0.038**  | ❌ 不显著   |
| +年份   | **0.210** | **<0.001** | ❌ 不显著   |

R²从0.03跃升到0.21，说明阳历月份和年份实实在在地解释了收益率——但五行变量在控制这些因素后**全部不显著**。

## 5 讨论：为什么人们觉得"有规律"？

一个合理的疑问：既然毫无关系，为什么民间总有"五行炒股"的说法？

答案藏在**日历效应（Calendar Effect）混淆**中。

天干地支首先是一套历法系统。例如：

- **金（庚辛）** 主要出现在阳历8-9月（秋季）——这个时期A股常有政策利好或秋收行情
- **火（丙丁）** 频繁出现在阳历5-6月（夏季）——五穷六绝的历史说法与此吻合
- **水（壬癸）** 则多在冬季，A股常有年末资金面偏紧

这些是**月份效应**，不是五行效应。当人们观察"金日涨得多"时，其实看到的是"8月涨得多"。五行只是碰巧与阳历月份产生了共线性——它穿了阳历的衣服，却不是阳历本身。

我们的回归分析直接验证了这一点：加入月份控制变量后，五行信号即刻消失。

此外，人类的大脑是世界上最强大的模式识别器——它能在白噪声中找到人脸（想想云朵的形状），也能在随机数据中找到"规律"。如果我们反复查看数据足够久，**总能找到某种走势相吻合的时刻**。这就是所谓的"选择性注意偏差"（confirmation bias）。

## 6 结论

本研究以16年、3,833个交易日、9项统计检验的体量，检验了天干地支五行对农业银行股价的预测能力。**结论明确：没有统计上显著的证据支持五行对股价有预测作用。**

- ✅ 日频无差异（p=0.917）
- ✅ 周频无差异（p=0.212~0.307）
- ✅ 月频训练集不显著，测试集方向反转
- ✅ 稳健性检验不改变结论
- ✅ 回归混合效应可完全用阳历月份解释

这一零结果本身就是有价值的科学发现。它说明：**一个文化上迷人的假说，在数据面前是脆弱的。** 天干地支五行或许能解释世间万物的相生相克，但解释不了农业银行的K线图——至少以我们目前的统计工具来看是这样。

最后，我们想引用一句统计学格言来为本文收尾：

> **"没有证据不等于证据不存在，但16年的数据和9个检验的结果，足够让我们有底气说一句：该放下这个执念了。"**
