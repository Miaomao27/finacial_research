## Data Sources

Since Tushare free tier lacks `index_daily` access, used akshare `stock_zh_index_daily()` from East Money:

```python
import akshare as ak
df = ak.stock_zh_index_daily(symbol='sh000001')  # 上证指数
df = ak.stock_zh_index_daily(symbol='sz399006')   # 创业板指
df = ak.stock_zh_index_daily(symbol='sh000688')   # 科创50
df = ak.stock_zh_index_daily(symbol='sz399001')   # 深证成指
```

**Key**: akshare returns date, open, high, low, close, volume only. No 成交额. Compute pre_close/change/pct_chg from close column.

## Analysis Script

`scripts/index_wuxing_analysis.py <ts_code> <name>` — reusable analysis pipeline that:

1. JOINs daily_quote with trade_calendar for 干支 labels
2. Runs 12 KW tests (日/周/月 × 天干/地支/五行干/五行支)
3. Runs OLS regression with month dummies
4. Runs winsorization robustness check
5. Outputs: 结论报告.md, 统计表/, 数据/
