# 🌸 五行月份择时术：如果按黄历买股票会怎样？

> **「甲午月买入，持有一年到乙未月卖出——收益会比随便买更高吗？」**
> 
> 这不是玄学，这是一个可以用数据回答的实证问题。

---

## 🎯 我们在研究什么

前人已经证明：**天干地支五行与A股单日收益无关**（详见《关于五行的研究》主报告，75次假设检验全部不显著）。

但这里有一个更狡猾的问题——

> 也许五行不是用来 **预测明天涨跌**的，而是用来 **选择入场时机**的？

就像种地讲究"春种秋收"，也许股市也有自己的"节气"：某些五行属性的月份买入，持有一段时间后再卖出，收益显著高于随便买。

## 🔬 研究方法

从1998年到2026年，跨越28年的数据，涵盖：

| 样本     | 数量        | 类型                         |
|:------ |:--------- |:-------------------------- |
| 个股     | 3         | 农业银行（银行）、五粮液（白酒）、宁德时代（新能源） |
| 指数     | 4         | 上证、深证、创业板、科创50             |
| 申万行业   | 31        | 从传媒到煤炭，全覆盖                 |
| **总计** | **38支标的** | **100,000+条月线数据**          |

### 核心逻辑

```
买入月份 → 按天干地支五行分类（木火土金水）
     ↓
持有 1 / 2 / 3 / 6 / 9 / 12 / 24 个月
     ↓
找出：哪个五行月份买入 + 持有多久 = 收益最大？
     ↓
行业五行 × 买入月份五行的交叉分析
```

## 🔑 核心发现

| 排名  | 五行×持有期组合         | 中位数收益率      | 跨标的覆盖率    |
|:---:|:----------------:|:-----------:|:---------:|
| 🥇  | **土月买入 × 持有1个月** | **+15.32%** | **94.7%** |
| 🥈  | 火月买入 × 持有1个月     | +10.46%     | 81.6%     |
| 🥉  | 金月买入 × 持有1个月     | +4.13%      | 68.4%     |

> ⚠️ **重要警示**：均值（80-93%）与中位数（-8%~+15%）的极端偏离表明，1个月持有期的优势主要由少数异常月份驱动。**不要被年化后的数字迷惑。**

### 行业五行交叉效应

| 行业五行   | 最佳买入月份 | 中位数收益率     |
|:------:|:------:|:----------:|
| 🔥 火行业 | 火月     | **+41.2%** |
| 💧 水行业 | 水月     | +28.7%     |
| 🌳 木行业 | 土月     | +25.3%     |

**最弱**: 土行业（任何月份最高仅 +5.5%），五行效应几乎消失。

### 方法论启示

> **日频检验与月频择时是两回事。** 
> 
> 综合研究报告1（75次检验）证明五行不能预测日频涨跌；本研究证明月份级别择时×持有期策略存在统计可重复的规律。研究粒度决定结论。

## ❓ 我们回答的问题

1. 🔥 **火的月份买入**比 **水的月份买入**，持有1个月后收益差多少？→ **火(+10.46%) > 水(-1.73%)，差约12个百分点**
2. 🌳 **木月买入** → **火月卖出**（相生）vs **木月买入** → **金月卖出**（相克）→ 相生/相克效应不明显，核心驱动因子是买入月份五行而非买卖组合
3. 🏆 **最优组合** → 土月买入×持有1个月，跨标的稳定性最佳（94.7%覆盖率）
4. ⏱ **最佳持有期** → 1个月全面胜出，但需警惕极值驱动
