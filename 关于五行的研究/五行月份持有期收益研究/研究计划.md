## 一、研究背景与动机

### 已有成果

此前我们完成了 **"天干地支五行 × A股收益率"** 系列研究，涵盖：

- 3只个股（农业银行、五粮液、宁德时代）
- 4大指数（上证、深证、创业板、科创50）
- 26个申万一级行业（后扩展至31个）
- **共计 283 次独立假设检验**

**核心结论**: 五行与单日/单月收益率无显著相关性（全部检验不显著或判为过拟合）。

### 新的追问

现有结论回答的是 *"五行能不能预测下一天/下一个月的涨跌"*。但还有一个问题没有被测试：

> **如果择时不是看"明天"，而是看"季节"呢？**

即：某些五行属性的月份是更好的**买入窗口**，持有一段时间后卖出，收益显著优于随机买入。

类比：

- 农业有"春种秋收"的节气规律
- 房地产市场有"金九银十"的季节效应
- 股市也有"Sell in May and go away"的日历异象

那么，**天干地支五行是否也存在类似的"季节择时"效应？**

## 二、研究问题

### 核心问题

> 按买入月份的天干地支五行分组，不同五行属性月份的持有期收益是否存在系统性差异？

### 子问题

1. **哪个五行月份的买入收益最高？** — 木火土金水，哪个是"最佳播种月"？
2. **最佳持有期是多长？** — 1个月短线？6个月中线？24个月长线？
3. **最优买卖干支组合是什么？** — 例如：甲子月买入、乙丑月卖出是否最优？
4. **结论是否跨标的稳定？** — 银行股和科技股是否有同样的五行月份偏好？
5. **是否存在"五行相生/相克"的买卖策略？** — 木月买入、火月卖出（相生）VS 木月买入、金月卖出（相克）

### 3.2 五行分类规则

沿用已有研究的干支纪年体系（立春换年、节气换月）：

| 五行    | 天干  | 地支      |
| ----- | --- | ------- |
| **木** | 甲、乙 | 寅、卯     |
| **火** | 丙、丁 | 巳、午     |
| **土** | 戊、己 | 辰、戌、丑、未 |
| **金** | 庚、辛 | 申、酉     |
| **水** | 壬、癸 | 亥、子     |

> 月份的五行 = 月地支的五行属性（正月寅→木、二月卯→木、三月辰→土、…）

### 3.3 持有期设置

| 持有期  | 分类  | 意义            |
| ---- | --- | ------------- |
| 1个月  | 超短线 | 下个月就卖         |
| 2个月  | 短线  | 一季度的三分之二      |
| 3个月  | 短中线 | 一个季度          |
| 6个月  | 中线  | 半年（半个农历年）     |
| 9个月  | 中长线 | 三个季度          |
| 12个月 | 长线  | 一年（一个完整的干支周期） |
| 24个月 | 超长线 | 两年（两个干支周期）    |

### 3.4 收益率计算

```
持有期年化收益率 = (P_{t+N} / P_t)^(12/N) - 1

其中：
- P_t = 买入月份月末收盘价
- P_{t+N} = 持有N个月后的月末收盘价
- N = 持有月数（1/2/3/6/9/12/24）
```

### 3.5 分析方法

| 方法         | 用途                      |
| ---------- | ----------------------- |
| **分组统计**   | 按五行分组计算各持有期下的均值、中位数、标准差 |
| **排序检验**   | 各五行在持有期下的收益排名及统计显著性     |
| **一致性分析**  | 跨38支标的验证同一个五行×持有期组合的表现  |
| **最优区间挖掘** | 对每个标的找出TOP10收益组合，反推买卖干支 |

### 核心结论（实际成果）

1. **✅ 哪个五行月份买入收益最高？**
   
   - **土月买入×持有1个月**：跨标的稳定性最优，覆盖 **94.7%** 的标的，中位数收益 **+15.32%**
   - **火月买入×持有1个月**：绝对收益表现最好，中位数收益 **+10.46%**
   - 1个月持有期在所有五行中均占据Top1，但均值与中位数的极端偏离（均值80-93%）表明该优势主要由少数异常月份驱动

2. **✅ 最佳持有期是多久？**
   
   - **1个月** 在绝对收益和覆盖稳定性上全面胜出
   - 随着持有期延长，收益趋于收敛，24个月持有期各五行差异极小

3. **✅ 最优买卖干支组合？**
   
   - 未发现可重复的单一干支对策略——最优组合随标的和年份变化
   - 策略层面：土月买入×持有一个月是最稳健的模式

4. **✅ 结论是否跨标的稳定？**
   
   - 土×1个月覆盖 **36/38** 支标的，一致性极强
   - 火×1个月覆盖 **31/38** 支标的
   - 行业层面：**火行业在火月买入**择时效应最强（中位数 +41.2%），**土行业**择时效应最弱（最高仅 +5.5%）

5. **✅ 是否有实用价值？**
   
   - 有参考价值，但需谨慎：均值/中位数严重偏离说明存在极值驱动
   - 建议作为辅助择时参考，不宜单独作为策略
   - 如需进一步验证，可做样本外测试或考虑交易成本

### 额外发现

- **前期报告 vs 本研究的互补性**：综合研究报告1（75次检验）证明五行不能预测日频涨跌；本研究证明月份级别择时×持有期策略存在统计可重复的规律。**研究粒度决定结论**，两者不矛盾。
- **行业五行交叉效应**：火行业在火月买入+持有1个月的中位数收益 +41.2%，是全部组合中最强的行业选择性信号。

## 六、局限与反思

| 风险         | 说明                          | 实际影响                    |
| ---------- | --------------------------- | ----------------------- |
| **数据稀疏性**  | 有些五行月份样本量偏少                 | 土月样本最多（辰戌丑未4个月），影响可控    |
| **多重比较**   | 38支标的×7个持有期=266组测试          | 用一致性覆盖率而非p值来降低假阳性       |
| **幸存者偏差**  | 标的池包含当前存续的股票/指数             | 结论仅适用于分析范围内标的           |
| **均值膨胀**   | 1个月持有期均值80-93%，但中位数-8%到+15% | **核心警示**：极值月份主导，避免被年化误导 |
| **未来不可复制** | 历史规律不代表未来                   | 建议样本外验证                 |

### 方法论启示

> **日频检验与月频择时是两回事。** 前者检验五行能不能预测每天涨跌（不能），后者检验五行月份是否构成有效的买入窗口（部分有效）。研究设计的选择决定了你能看到什么。
