# 📜 关于五行的研究 — 天干地支五行 × A股收益率检验

> **用科学的方法论，检验古老的东方智慧——天干地支五行，到底能不能预测A股涨跌？**
>
> 答案很遗憾：**不能。** 7个样本、75次假设检验、22,981个交易日的数据，结论高度一致——**五行与A股收益率无关。**

## 🏗️ 方法论框架

三层递进分析 + 双重稳健性检验：

```
Layer 1: 日频基线  → Kruskal-Wallis非参数检验
Layer 2: 周频过滤  → 周均收益率分组检验（消除噪声）
Layer 3: 月频验证  → 月均收益率 + 70%/30% 样本外切分
         └─ OLS回归 → 控制阳历月份效应
         └─ 稳健性   → Winsorization缩尾后重跑
```

## ⚡ 一句话结论

> **天干地支五行，做不了A股的预测指标。**
>
> 至少在这个数据集上——7个样本、覆盖银行/白酒/新能源/大盘/成长/科创，从2010年到2026年，
> 我们用统计学的放大镜看了又看，没有找到任何可靠的"五行信号"。
>
> 但这不代表研究没有价值——阴性结果本身就是科学发现。
> 它告诉我们：投资决策，还是要回归基本面和技术面，而不是看黄历。📅
